🚀 Django REST Framework Studies

Projeto desenvolvido durante meus estudos de Django e Django REST Framework.

📌 Sobre o projeto

Este repositório foi criado para praticar:

criação de APIs,
organização de projetos Django,
testes,
internacionalização,
e arquitetura backend.

O projeto possui múltiplos apps organizados separadamente para simular uma aplicação maior e mais estruturada.

🛠️ Tecnologias utilizadas
Python
Django
Django REST Framework
Pytest
HTML
CSS
📂 Estrutura do projeto
authors/ → gerenciamento de autores
blog/ → sistema de blog
news/ → notícias/publicações
tags/ → sistema de tags
tests/ → testes automatizados
